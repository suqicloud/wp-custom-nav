# 小半WordPress自定义网址导航

源于最近有一个小行业的导航记录，因为需求不高，所以就先用WordPress插件来实现。
之前改过六零导航的纯html页面版本，但是后面新增导航不方便，还是有后台管理的方便一点。

这是插件，所以前台页面不一定兼容你的主题，样式问题，自己改下就行。
还有就是如果你的主题内置的样式，也是采用阿里图标，比如 icon-qq 这种，就会导致导航页面联系方式板块的QQ图标不显示，所以也需要根据你自己的主题调整。

## 基础功能
- 导航分类管理
- 内容管理

## 自定义功能
- 背景颜色自定义  
- 标题文字自定义  
- 公告内容自定义  
- 广告位自定义

## 布局模式
- 三栏布局：
  - 左栏：分类导航
  - 中栏：主内容区  
  - 右栏：功能扩展区

## 内置组件
- 实时时钟
- 顶部搜索栏
- 文章展示
- LyToday-JS热搜榜

## 其他功能
- 联系方式展示
- 网站收录申请
